# 古法纸浆发酵记录

运行：

```bash
npm start
```

访问`http://localhost:3039`。数据保存在`data/paper-pulp-fermentation.json`。

## 业务模块

- `src/split.js`：拆分计算——纯函数，负责拆分校验（各份干浆重量合计不超过原批余量）、合并检视（发酵天数/异常次数/缸位）与合并批次构造。
- `src/ledger.js`：批次账——批次建档、拆分、合并、抄纸投料、更正/退回、投料复核与当日产量，所有台账变动都经过这里。
- `src/page.js`：页面动作——页面结构与浏览器端交互。
- `server.js`：HTTP 路由，把请求接到对应业务模块。

## 规则

- 拆分后各份干浆重量合计不得超过原批余量；每份记录母批与来源批次。
- 合并前检视各份发酵天数、异常次数、缸位；任一份处于异常观察即拒绝合并并指出编号。
- 投料按实际称重扣减批次余量，记录来源批次与操作人。
- 来源批次更正或退回后，其关联投料单（含拆分/合并出的下游批次的投料单）转为待复核，不计入当日产量；复核为"有效"后重新计入，"作废"则永久剔除（不补回余量，浆已消耗）。
